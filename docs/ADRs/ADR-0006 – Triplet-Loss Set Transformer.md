# ADR-0005: Learn Outfit Representations Using a Triplet-Loss Set Transformer

## Status

Accepted

---

## Context

WardrobeGenie generates outfit recommendations by combining garments retrieved from a user's digital wardrobe.

Unlike traditional recommendation problems, an outfit is not a single item but an **unordered set of garments** whose compatibility depends on their collective appearance rather than isolated pairwise relationships.

The recommendation model therefore needed to:

* Process a variable number of garments.
* Remain invariant to garment ordering.
* Learn holistic outfit compatibility.
* Produce representations suitable for downstream personalization.
* Adapt efficiently to evolving fashion trends and user data.

Several approaches were considered before selecting the final architecture.

---

## Decision

WardrobeGenie represents outfits using a **Triplet-Loss Set Transformer**.

Instead of directly predicting a compatibility score, the model projects an outfit into a **128-dimensional Style Space**, where stylistically similar outfits occupy nearby regions.

The learned embedding is later consumed by the personalization layer, allowing recommendations to be ranked according to each user's evolving style preferences.

---

## Rationale

### Sets Rather Than Sequences

An outfit is naturally an unordered collection of garments.

For example,

```text
Shirt + Jeans + Sneakers
```

and

```text
Sneakers + Shirt + Jeans
```

represent the same outfit.

Sequence-based architectures introduce an artificial ordering that has no semantic meaning for this problem.

Set Transformers are specifically designed for permutation-invariant learning, making them a natural architectural choice for outfit representation.

---

### Holistic Compatibility

Early designs considered evaluating compatibility using pairwise relationships between garments.

For example:

* Shirt ↔ Pants
* Pants ↔ Shoes
* Shirt ↔ Shoes

Although computationally simple, pairwise scoring cannot capture interactions that emerge only when considering the complete outfit.

The Set Transformer jointly attends to every garment within the outfit, allowing compatibility to emerge from the entire combination rather than independent garment pairs.

---

### Learning a Style Representation

Rather than predicting whether an outfit is simply "good" or "bad," the Stylist learns a **continuous style representation**.

Each outfit is embedded into a shared 128-dimensional Style Space where geometric distance reflects stylistic similarity.

This representation is significantly more expressive than a scalar compatibility score and enables downstream personalization without modifying the recommendation model itself.

---

### Triplet Loss

Triplet loss organizes the Style Space through relative similarity rather than absolute class labels.

Each training sample consists of:

* **Anchor:** Reference outfit
* **Positive:** Stylistically compatible outfit
* **Negative:** Incompatible outfit

The optimization objective minimizes the distance between anchors and positives while maximizing the distance to negatives.

As training progresses, visually and stylistically similar outfits naturally cluster together within the learned embedding space.

---

### Adaptation to Data Drift

Fashion trends continually evolve, making data drift an expected characteristic of the recommendation domain.

Learning a style embedding instead of a fixed compatibility function makes retraining considerably simpler.

Rather than requiring manually engineered compatibility scores, the model only requires examples of complete outfits. These naturally become new anchor-positive examples for triplet learning, allowing the embedding space to adapt as new fashion trends emerge.

As users contribute additional wardrobe images and outfit combinations, the recommendation model can continuously improve without redesigning the underlying architecture.

---

### Decoupled Perception and Recommendation

The Stylist operates exclusively on **512-dimensional garment embeddings** generated by the perception layer rather than raw images.

This separation decouples recommendation learning from computer vision.

Improvements or replacements to the visual encoder can therefore be made independently, provided the embedding interface remains compatible.

This modular design simplifies experimentation and allows individual components of the pipeline to evolve without requiring retraining of the entire recommendation system.

---

### User-Independent Recommendation Model

The Stylist learns a general representation of outfit compatibility that is independent of any individual user.

Personalization is intentionally delegated to a separate architectural component responsible for modeling each user's preferences.

Separating representation learning from personalization improves modularity and allows the same recommendation model to serve all users while enabling individualized ranking downstream.

---

## Alternatives Considered

### Pairwise Compatibility Networks

**Pros**

* Simple implementation
* Fast inference
* Easy optimization

**Cons**

* Limited to pairwise garment relationships
* Cannot capture holistic outfit compatibility

---

### Classification-Based Compatibility

Predict a single compatibility score directly.

**Pros**

* Straightforward training objective
* Simple ranking

**Cons**

* No reusable outfit representation
* Difficult to personalize
* Limited ability to measure stylistic similarity

---

### Graph Neural Networks

Treat garments as nodes connected by compatibility edges.

**Pros**

* Explicit relationship modeling
* Flexible graph structures

**Cons**

* Increased implementation complexity
* Additional graph construction overhead
* Limited benefit given the relatively small outfit sizes

---

### Triplet-Loss Set Transformer (Selected)

**Pros**

* Naturally permutation invariant
* Learns holistic outfit representations
* Produces reusable style embeddings
* Supports downstream personalization
* Handles variable-sized outfit sets
* Easily adapts through continual retraining as new outfit data becomes available

**Cons**

* More complex training procedure
* Performance depends on effective triplet sampling
* Requires careful hard-negative mining

---

## Consequences

### Positive

* Captures outfit compatibility as a holistic concept rather than isolated garment pairs.
* Produces a reusable embedding space for downstream personalization.
* Generalizes naturally to variable-sized outfit combinations.
* Simplifies adaptation to evolving fashion trends through retraining.
* Decouples recommendation learning from computer vision, improving modularity.
* Enables future improvements to the perception layer without redesigning the recommendation engine.

### Negative

* Training is computationally more expensive than direct classification.
* Embedding quality depends on the quality of triplet construction.
* Hard-negative mining significantly influences convergence and final representation quality.

---

## Future Considerations

Future iterations may investigate alternative metric-learning objectives, such as supervised contrastive learning or listwise ranking losses, while preserving the learned Style Space abstraction.

As WardrobeGenie accumulates larger collections of real user outfits, periodic retraining can continuously refine the embedding space, allowing the recommendation engine to remain aligned with evolving fashion trends without requiring architectural changes.
